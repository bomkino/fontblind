# FontBlind 3.7.0 — prepared release notes

**Not published. Current source is ahead of the latest public release, v3.4.0.**

FontBlind 3.7.0 adds one deliberately narrow experimental Linux package target: current Garuda Linux on its rolling Arch base, KDE Plasma 6, Wayland-first, x86_64 Dell G7. It uses the existing private loopback runtime and default browser rather than adding Electron, Qt, GTK, a daemon, cloud processing, telemetry, or a second font engine.

Automated evidence covers reproducible package bytes, package metadata and ownership, exact checksums, ELF architecture/linkage, root and argument refusal, pacman installation, the complete frozen-runtime and multiscript gauntlet, KDE/Wayland lifecycle simulation, second-launch reuse, authenticated shutdown, reconnect-state cleanup, clean uninstall, and macOS regression packaging.

The physical Dell G7 / Garuda / KDE journey remains unperformed. This note does not claim real hardware, attended Linux accessibility, Developer ID signing, notarisation, stapling, or generic Linux support.
