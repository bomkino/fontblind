# Italics Lab + Variable Lab

Research snapshot: 25 August 2026, updated for current source on 27 August 2026. FontBlind implements deterministic local lanes for static mechanical Oblique, mechanical `slnt`, real-donor `wght`, real-donor `wdth`, independent `wght` + `wdth`, and verified static-instance export. Designed Italic, optical/custom axis authoring, repair bundles, and model proposals remain roadmap work. Current repository truth lives in [`maintenance/REPOSITORY_STATE.md`](maintenance/REPOSITORY_STATE.md).

## Straight answer

Yes, the browser product can grow into both labs. No, one old static font cannot honestly yield every meaningful variable axis automatically.

An OpenType axis is a designer-defined variable with a minimum, default, and maximum. OpenType registers `ital`, `opsz`, `slnt`, `wdth`, and `wght`, and also permits custom axes. The container can encode all of these; a single drawing does not contain the missing design decisions.

Use four truth labels internally:

1. **Real master axis** — built from actual donor masters or authored extremes.
2. **Mechanical axis** — generated by a declared geometric operation.
3. **Model proposal** — a local model's candidate, not accepted output.
4. **Hand-reviewed result** — repaired and accepted by a reviewer working with Codex.

## No cloud API / Codex subscription boundary

The standalone app must work with deterministic local tools and optional local models. It will not contain a hidden paid-model call.

Codex subscription assistance works as an explicit authoring loop:

1. The lab emits an anonymous source bundle: UFO/designspace, axis brief, proofs, and repair queue.
2. The reviewer opens that bundle in a Codex task.
3. Codex runs local tools, edits masters, repairs interpolation failures, and returns candidates into the bundle.
4. The browser watches the bundle and presents comparisons for acceptance.
5. FontBlind runs again after compilation so the final native and WOFF2 files have no original labels.

This uses Codex as the collaborator in the task, not as an automatic model embedded in the app. Embedding Codex invisibly would require a separate supported product/API integration.

## Oblique Lab — implemented

### Current stable lane

- Preserve the upright TrueType font as the source of truth.
- Apply a controlled 4–20 degree affine slant to simple and composite outlines.
- Remove invalidated TrueType instructions, update Oblique metadata, and verify glyph topology, metrics, shaping structure, WOFF2 round-trip, and zero-ID output.
- Compile either a separate companion face or a variable font with upright `slnt=0` and a verified right-leaning negative-degree endpoint.
- Expose a live browser slider and registered range CSS without exposing source identity.

This can be useful and repeatable. It must be called **Oblique**, not designed italic.

### Experimental lane: Designed Italic

- Start from the oblique candidate.
- Create proper italic constructions where the design needs them: common examples include `a`, `f`, and `g`, but the decision is typeface-specific.
- Repair terminals, joins, counters, rhythm, overshoot, spacing, anchors, marks, ligatures, and language coverage.
- Keep every generated glyph as a reviewable candidate; do not auto-promote a whole font.

A real italic is a drawing problem, not a shear. The accepted artifact remains a separate companion or an authored `ital` system.

## Variable Lab

### Tier A — existing variable font repair

Inspect, repair, subset, instance, and re-export an existing VF. This is the least speculative tier.

### Tier B — Family Merge: `wght` + `wdth` implemented

The current app accepts 2–12 genuinely compatible static TrueType donors. It reads weight and registered width-percentage coordinates from `OS/2`, never filenames, and fails closed on mismatched glyph order, cmap, units-per-em, outline topology, or duplicate coordinate tuples.

One-axis families may vary weight or width. Two-axis families need a real base and independent extreme masters on both axes. A diagonal pair such as Condensed Regular plus Normal Bold is rejected: it proves only one coupled movement, not two independently controllable axes. Every donor coordinate is reinstanced and compared for geometry, metrics, anchors, cmap, and shaping before the output is committed.

- Recover editable sources.
- Rebuild compatible point structures.
- Preserve donor geometry at exact master locations.
- Freeze or queue glyphs that cannot interpolate safely.
- Build UFO/designspace checkpoints.
- Compile with FontTools/fontmake.
- Restore and verify metrics, kerning, anchors, OpenType layout, and variation tables.
- Export variable TTF, WOFF2, and optional static instances.

The strongest current inspiration is `static-to-variable`: its MIT pipeline redraws separate weights onto a shared skeleton and skips glyphs it cannot convert cleanly instead of shipping broken interpolation.

### Tier C — mechanical axes

- `slnt`: affine slant; useful, predictable, and implemented with exact endpoint checks.
- `wdth`: horizontal transformation plus spacing/stroke corrections; synthetic without real width donors.
- `wght` / `GRAD`: outline operations can draft darker/lighter forms, but need join, counter, overshoot, and spacing repair.
- spacing, roughness, shadow, serif length, roundness: valid custom axes only when their mechanical meaning is explicit.

### Tier D — local model proposals

NIV is the first credible public attempt at generating `wght`, `wdth`, `slnt`, and `opsz` deltas from one static TrueType font. It is not bundled. Treat it as a quarantined research candidate generator only:

- fixed topology cannot invent genuine italic alternates;
- composites and non-Unicode glyph coverage are incomplete;
- output lacks a full production treatment of metrics, layout variation, hinting, and axis semantics;
- current code is TrueType-focused;
- its NIV Research License allows only non-commercial research, educational, and academic use; it grants no patent rights and is not an unrestricted product dependency;
- the public implementation is young, trains with roughly 50 GB of memory, and its sample generation path targets a limited Unicode range.

It may be worth a separate local sandbox after Family Merge works. It must never auto-label its result “production-ready.”

### Tier E — authored optical/custom axes

`opsz`, `ital`, contrast, grade, serif, and unusual custom axes need actual masters or deliberate authoring. Codex can help construct and repair those masters; it cannot recover ground truth that is absent from one file.

## Open-source findings that shaped the Labs

- **FontTools varLib** remains the compilation core. It supports n-dimensional designspaces, but its masters still need truly interpolatable structures. FontBlind therefore validates topology, model shape, exact donor locations, and WOFF2 round-trips around varLib instead of treating a successful compile as proof.
- **Fontra** validates the browser interaction model: live axis sliders, local Python service, designspace/UFO workflows, anchors, kerning, features, and RTL preview. Fontra is GPL-3.0; FontBlind borrows interaction principles, not code.
- **static-to-variable** is an interesting MIT-licensed topology-repair experiment. It redraws separate weights onto a shared skeleton and skips glyphs it cannot convert. That is inspiration for a future repair queue, not a dependency or a reason to weaken the current exact-donor gate.
- **FontForge** explicitly describes automatic oblique/italic transformations as imperfect starting points. This supports FontBlind's honest Oblique label and the separate future lane for designed italic repair.
- **Diffenator2** and **Fontspector** are strong future QA additions for visual diffs, axis cross-products, and OpenType profile checks. They are not bundled into the packaged runtime.
- **NIV** stays outside the product for both maturity and licence reasons. A later experiment would run in a separate local sandbox with explicit candidate/review status.

## App interaction model

Borrow principles, not code, from Fontra:

- anonymous master map and axis sliders;
- live interpolation;
- source/default/extreme overlays;
- glyph-level failure heatmap;
- frozen-glyph queue;
- kerning, anchor, feature, and RTL preview;
- repair bundle round-trip with local files.

The three tools live in one native macOS window but keep separate workbenches. Blind remains the clean one-drop front door and the zero-ID exit contract applies to every lane.

## Acceptance gates

- Default/master locations match their donors.
- Compatible contours/components or explicit frozen glyphs.
- No empty/intersecting/clipped glyph surprises across axis corners and sampled interiors.
- Metrics, kerning, marks, anchors, GSUB/GPOS/GDEF, line metrics, and variation tables survive.
- HarfBuzz shaping, FreeType/CoreText raster, OTS/Fontspector, and Chrome/Firefox/WebKit loads pass.
- Variable axes behave at min/default/max, every corner, and random interior samples.
- Final FontBlind pass removes all original identity and embedding labels.
