# Linux artifacts

A successful x86_64 package job emits four files:

- `FontBlind-3.6.0-x86_64.AppImage`
- `FontBlind-3.6.0-x86_64.AppImage.sha256`
- `FontBlind-3.6.0-linux-x86_64.tar.gz`
- `FontBlind-3.6.0-linux-x86_64.tar.gz.sha256`

They remain temporary pull-request artifacts until a repository owner explicitly approves a tagged release.
